Use appgen to make a small web app for a neighborhood tool library.
Members borrow tools. A tool has a name, a category (garden, kitchen, or
workshop), and a note about its condition. A loan has the member, the
tool, the date of the loan, the due date, and the date of the return. A
member can mark a loan as returned. Write the app definition in
app.yaml, and generate a FastAPI app into ./app.
